# php-xqkeji

xqkeji 低代码开发框架的 PHP C 扩展（二进制分发），包含 Windows（.dll）与 Linux（.so）平台的 PHP 扩展文件。

本仓库提供的是**框架运行所需的 PHP 扩展二进制包**；框架本体（低代码开发框架）为闭源软件。
